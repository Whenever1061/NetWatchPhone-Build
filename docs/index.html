Archive safety

Source stays private.

The public site is for installable packages and recovery access. Proprietary source, signing material, developer keys, environment files and private configuration are not intended for public download. Private vault buttons use GitHub authentication so the archive can remain locked while still being reachable from this page when you need it.

Do not erase the computer copies until each private vault has been created, uploaded and checksum-verified.

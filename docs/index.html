A privacy-focused Android phone experience with caller profiles, call-log control, local ringtone generation, Albuquerque/Sandia glass visuals, contact photos, weather, screening tools and signed updates.

Download for AndroidView source on GitHub

Private by design

Core dial-pad sounds and NetWatch ringtone synthesis run locally. The app is built around direct user control instead of advertising telemetry.

Glass phone interface

Translucent lens-style contact and recent-call tiles keep the Albuquerque and Sandia background visible while saved contact photos stay front and center.

Signed updates

Stable Android releases are signed and published through the NetWatch update channel with SHA-256 package verification.

Android download

Install NetWatch Phone

The current stable APK can be installed on compatible Android phones. NetWatch Phone currently targets Android and requires Android 10 or newer. iPhone/iOS installation is not supported.

Download stable APKRelease details
Android may ask you to allow installation from your browser or file manager. Because NetWatch can act as a phone app, Android may also ask you to approve restricted settings and the default Phone role.
